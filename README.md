# 👋 성기환 | Backend & Cloud Infra

8년차 소프트웨어 엔지니어로서 **세무·금융 도메인**, **고가용 인프라 설계**, **클라우드 비용 최적화**, **이벤트 기반 아키텍처**에 특화된 경험을 보유하고 있습니다.  
대규모 트래픽을 안정적으로 처리하는 아키텍처를 구축해왔으며, AWS EKS/ECS, WebRTC, Socket.io를 활용한 **실시간 서비스 서버 개발**과 **클라우드 운영 효율화**에 강점을 가지고 있습니다.  

특히, **세무·금융 특화 서비스**를 다년간 설계·운영하며 복잡한 비즈니스 로직을 안정적이고 확장 가능한 시스템으로 구현한 경험이 있습니다.  
또한 **클라우드 전문가**로서 실제 프로젝트에서 월 **$13,000 → $4,000 이하로 비용 절감**한 성과를 만들어냈습니다.  

---

## 🚀 핵심 기술 스택
- **Backend**: NestJS, TypeScript, TypeORM, Java, Spring Boot, Kotlin, Express.js  
- **실시간 통신**: WebRTC, Socket.io, Kafka, Flink  
- **Database**: MySQL(Aurora), PostgreSQL, MongoDB(DocumentDB), Redis  
- **Infra & Cloud**: AWS (EKS/ECS, Lambda, S3, RDS, DynamoDB), Kubernetes, Docker, Helm, ArgoCD  
- **CI/CD & DevOps**: GitHub Actions, Jenkins, GitOps, Terraform  
- **기타**: WebRTC, gRPC, ElasticSearch  

---

## 🏆 주요 프로젝트

### 1. 클라우드 비용 최적화 & 인프라 운영 (AWS EKS)
- **성과**: 월 $13,000 → $4,000 이하로 비용 절감  
- 미사용 리소스 정리, 다수의 EKS 클러스터 통합  
- 30+ ELB를 1개의 ALB + Host-Based Routing으로 전환  
- 무거운 EC2 워크로드를 Lambda 기반 서버리스 구조로 이전  
- **기술**: AWS (EKS, EC2, Lambda, RI, ALB)

---

### 2. Socket.io & Redis 기반 실시간 서비스
- 실시간 챗 서비스 서버 개발
- 안정적인 **수만 동시 접속 처리** 및 낮은 지연 시간 확보
- **기술**: NestJS, Socket.io, Redis, AWS EKS

---

### 3. 세무·금융 데이터 기반 서비스 (도메인 전문성)
- 홈택스, 근로복지공단, 카드사, 은행 데이터를 자동 수집·분석  
- 종합소득세 신고, 환급 계산, 세무 리포트 서비스 구현  
- 복잡한 세무 로직을 **TypeORM + 파티셔닝 DB 설계**로 안정화  
- Redis Lua Script 기반 분산락, 대기열 시스템, API Rate Limit 구축 
- **기술**: NestJS, NextJS, MySQL(Aurora), Redis, AWS (EKS, Lambda, RDS)

---

### 4. RAG 기반 병원/CS 데이터 플랫폼
- 사내 CS 로그·병원 행정 데이터를 RAG 기반으로 검색·분석  
- LangChain + OpenAI API 연동 → 사용자 친화적 요약/인사이트 제공  
- 쿼리 라우팅, 프롬프트 엔지니어링으로 응답 속도 최적화  
- **기술**: NestJS, PostgreSQL, AWS, LangChain, OpenAI API

---

### 5. Kafka & Flink 실시간 금융 데이터 처리
- 일간 100만 건 이상 데이터 스트리밍 처리  
- Exactly-Once 모드의 성능 병목 → Redis 중복 제거 전략으로 해결  
- 주식·거래소 API 데이터 파이프라인 안정화  
- **기술**: Kafka, Flink, Redis, Java, Python, InfluxDB

---

## 📊 성과
- **대규모 트래픽 안정화**: Kafka/Flink 아키텍처로 초당 수천 건 스트림 안정 처리  
- **클라우드 비용 최적화**: AWS 인프라 최적화로 월간 비용 70% 이상 절감  
- **세무·금융 도메인 전문성**: 복잡한 세무 로직 자동화 서비스 다수 구축  
- **실시간 서비스 역량**: WebRTC, Socket.io 기반 화상/실시간 통신 서버 개발 경험  
- **CI/CD 자동화**: GitHub Actions + ArgoCD + Helm 기반 무중단 배포 환경 구축
